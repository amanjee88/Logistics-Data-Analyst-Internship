In this task, I developed and executed a reproducible data collection simulation, cleaning and preprocessing workflow for logistics shipment records using Python and pandas. As a public reference for the supply-chain context, I selected the DataCo SMART SUPPLY CHAIN FOR BIG DATA ANALYSIS dataset, Version 5, published in Mendeley Data by Constante, Silva and Pereira (2019). The reference dataset covers supply-chain activities such as provisioning, production, sales and commercial distribution. To keep the implementation lightweight and easy to reproduce on a standard laptop, I did not claim to process the original DataCo records. Instead, I created a compact synthetic training fixture with intentionally inserted quality problems that mirror common issues in operational shipment data.

The workflow starts by loading raw CSV fields as text so parsing decisions remain explicit. It trims whitespace, standardizes region names, vehicle types and first-attempt status labels, parses mixed date formats, removes exact duplicate rows, and identifies conflicting shipment identifiers. Records missing required identifiers, order dates, promised-delivery dates or region values are separated into a manual-review file rather than silently guessed or discarded. The pipeline also validates numeric business rules: distance and shipment weight must be positive, while transportation cost must be non-negative. Invalid numeric values are marked missing and imputed with documented median rules. Each imputed value is tracked using a Boolean flag.

Potential statistical outliers are detected with the 1.5-times-IQR rule and retained with flags for further investigation instead of being automatically deleted. Actual delivery timestamps are not invented for pending shipments; impossible or unparseable timestamps are left missing and marked for review. The pipeline exports a cleaned dataset, records for manual review and an audit CSV containing the observed row counts and treatment decisions. The report includes the field dictionary, a workflow diagram, code examples, executed output counts, reproducibility instructions, limitations and references. All processed records and numerical results in this implementation are synthetic demonstrations, not actual performance figures from a logistics company. This task establishes a transparent data-quality foundation for the next stage of exploratory analysis and visualization.
